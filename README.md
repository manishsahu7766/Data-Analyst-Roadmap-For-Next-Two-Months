# Day-01-Data-Domains-Career-Roadmap.md

Data Analyst -> Data Engineer -> Data Scientist -> AI/ML Engineer


**1)Data Analyst**
Reads existing data, builds reports & dashboards, helps business decisions. 

**Key Skills**
-Excel / SQL
-Data Visualization (Power BI, Tableau)
-Communication & Business Understanding

**Example**
Create a sales dashboard to find top performing products.


**2)Data Engineer**
Builds pipelines & infrastructure to data flows clearly to everyone else.

**Key skills**
-SQL
-Python
-ETL/Data Pipelines
--Cloud (AWS, Azure, GCP)
-Databases & Big Data (Hadoop, Spark)

**Example**
Build a pipeline to move data from multiple sources to a data warehouse.


**3)Data Scientist**
Uses Statistics & ML to predict, forecast, and run experiments.

**Key Skills**
-Python (Pandas, NumPy, scikit-learn)
-Statistics
-Machine Learning
-Data Visualization

**Example**
Predict customer churn using past user data.


**4)AI/ML Engineer**
An Al/ML Engineer builds and deploys intelligent System that learns from data to make predictions, automate tasks, and solve real world problems.

**Key Skills**
-Python
-Machine Learning & Deep Learning
-Model Deployment (Docker, Kubernetes)
-Cloud (AWS, Azure, GCP)
-MLOps

**Example**
Build a chatbot that understands user queries and gives smart responses.
